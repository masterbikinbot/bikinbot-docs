# Pilih Model AI

BikinBot mendukung **36+ model AI** dari berbagai provider. Setiap model punya karakteristik berbeda — kecepatan, biaya, kemampuan, dan spesialisasi.

## Cara ganti model

### Via Dashboard

1. Buka **Settings → Pilihan Model**
2. Pilih model dari dropdown
3. Atau ketik ID model custom (format: `openrouter/<vendor>/<model>`)
4. Simpan — bot restart otomatis ~15 detik

### Via Telegram (sementara)

Ketik `/model` di bot untuk membuka picker model. Pilihan ini **hanya berlaku untuk sesi aktif** — tidak permanen.

Untuk ganti model secara permanen, gunakan perintah:
```
ganti model ke deepseek/deepseek-v4-flash
```
Bot akan konfirmasi dan menjalankan pergantian permanen.

<Callout type="info">
  Ketik `/status` untuk melihat model yang sedang aktif digunakan bot kamu.
</Callout>

## Cara kerja Model Picker di Telegram

Ketik `/model` di Telegram untuk melihat 36+ pilihan model:

```
/model openrouter
  → Select a provider: openrouter (36)
    → Semua model tersedia
```

Pilih model dari list untuk **sesi override** (sementara). Untuk permanen, minta bot via chat.

<Callout type="warning">
  **Context window besar = lebih mahal.** Model dengan 1M+ context window akan memproses seluruh history percakapan yang lebih panjang → biaya lebih tinggi per pesan jika punya banyak riwayat chat. Gunakan `/new` secara berkala untuk reset context.
</Callout>

## Custom model

Kamu bisa menggunakan model OpenRouter apa pun, tidak terbatas pada daftar di atas:

```
openrouter/<vendor>/<model-id>
```

Contoh:
```
openrouter/meta-llama/llama-3.3-70b-instruct
openrouter/qwen/qwen3-coder-30b-a3b-instruct
```

Cek semua model yang tersedia di [openrouter.ai/models](https://openrouter.ai/models).
