# Apa itu BikinBot.ai?

**BikinBot.ai** adalah platform yang memungkinkan siapa saja membuat **AI Agent personal** di Telegram atau WhatsApp — tanpa coding, tanpa server sendiri.

Bot kamu ditenagai oleh model AI terbaru (GPT-5, Claude, Gemini, dan 30+ model lainnya) dan bisa melakukan jauh lebih banyak dari chatbot biasa.

## Bukan sekadar chatbot

BikinBot berbeda dari chatbot biasa karena AI Agent kamu bisa:

- **Mengingat** konteks percakapan, nama, dan preferensi kamu
- **Membaca** file PDF, DOCX, gambar, audio, video
- **Browsing** internet secara real-time
- **Menjalankan** kode dan script (Python, Node.js, bash)
- **Membuat** gambar, video, dan musik dari teks
- **Terjadwal** mengirim reminder atau laporan otomatis

## Cara kerja

```
Kamu (Telegram/WhatsApp)
    │
    ▼
OpenClaw Gateway (per-bot, isolated)
    │
    ▼
BikinBot.ai Platform (Fastify API)
    │
    ▼
OpenRouter → GPT-5 / Claude / Gemini / dll
```

Setiap user mendapat **satu bot terpisah** yang berjalan di server dedicated dengan isolasi penuh — bukan shared resource.

## Tier & Harga

| Tier | RAM | CPU | Disk | Harga |
|------|-----|-----|------|-------|
| **Basic** | 2 GB | 0.5 vCPU | 5 GB | ~Rp 200rb/bln |
| **Pro** | 4 GB | 1 vCPU | 10 GB | Rp 750rb/bln |
| **Ultra** | 8 GB | 2 vCPU | 25 GB | Rp 1.25jt/bln |

Harga di atas adalah biaya subscription platform. **Kredit AI** (untuk penggunaan model) diisi terpisah dan dipotong per pesan.

<Callout type="info">
  **Estimasi kredit:** Model gratis tidak memotong kredit. Model standar (Gemini Flash, GPT-4.1 Mini) ~Rp 1–5 per pesan. Model premium (GPT-5, Claude Opus) ~Rp 50–200 per pesan.
</Callout>
