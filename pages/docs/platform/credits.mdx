# Kredit & Billing

BikinBot menggunakan sistem **kredit AI** yang dipotong per pesan berdasarkan model yang dipilih.

## Dua komponen biaya

| Komponen | Fungsi | Cara bayar |
|----------|--------|-----------|
| **Subscription** | Akses platform + server dedicated | Top-up Rp 200rb–1.25jt/bulan |
| **Kredit AI** | Konsumsi model AI per pesan | Top-up terpisah, pay-as-you-go |

<Callout type="info">
  **Subscription** memberi kamu server bot yang berjalan 24/7. **Kredit AI** dipotong setiap bot merespon chat.
</Callout>

## Cara top-up kredit

1. Buka dashboard BikinBot → **Billing**
2. Klik **"Top Up Kredit"**
3. Pilih nominal (minimal Rp 10.000)
4. Bayar via:
   - **QRIS** (scan dengan aplikasi apapun)
   - **Virtual Account** BNI, BRI, Mandiri, Permata, CIMB
5. Kredit masuk dalam **1–2 menit** setelah pembayaran terkonfirmasi

## Estimasi biaya per pesan

| Model | Estimasi per pesan* |
|-------|---------------------|
| Gratis (Gemma, Llama free) | Rp 0 |
| Hemat (Gemini Flash, GPT-4.1 Mini) | Rp 1–5 |
| Standar (Gemini Pro, Claude Sonnet) | Rp 10–50 |
| Premium (GPT-5, Claude Opus) | Rp 50–500 |

*Estimasi untuk pesan biasa (bukan generate gambar/video). Harga aktual tergantung panjang pesan dan response.

## Generate media (biaya terpisah)

| Tipe | Estimasi biaya |
|------|----------------|
| Generate gambar | Rp 600–3.000 per gambar |
| Generate video | Rp 600–4.000 per video (tergantung durasi) |
| Generate musik | Sesuai API key pribadi kamu |

## Cek saldo kredit

```
cek saldo kredit saya
```

Atau lihat di dashboard → **Billing** → kolom Kredit AI.

## Alert kredit hampir habis

Saat kredit mendekati batas rendah:
- Bot mengirim **pesan peringatan langsung di chat**
- Dashboard menampilkan notifikasi
- Bot **tetap berjalan** sampai saldo benar-benar habis

## Kredit habis — apa yang terjadi?

Jika kredit habis:
1. Bot berhenti merespon chat
2. Muncul pesan: "Kredit AI habis, top-up di bikinbot.ai/billing"
3. Bot **tidak di-delete** — cukup top-up, bot langsung aktif lagi

<Callout type="warning">
  **Kredit AI ≠ Saldo Referral.** Kredit AI hanya bisa dipakai untuk penggunaan bot. Saldo referral (komisi) hanya bisa di-withdraw ke rekening.
</Callout>

## Tips hemat kredit

- Gunakan model **Gemini Flash** atau **DeepSeek V4 Flash** untuk chat sehari-hari
- Ketik `/new` secara berkala untuk reset context (pesan baru = input lebih pendek = lebih murah)
- Pilih model **gratis** untuk pertanyaan sederhana
- Monitor penggunaan di dashboard → **Analitik**
