# Program Referral

Ajak teman menggunakan BikinBot dan dapatkan **komisi 10% dari setiap pembayaran** yang mereka lakukan — selamanya, bukan cuma sekali.

## Cara mulai

1. Login ke [bikinbot.ai](https://bikinbot.ai) dengan akun yang punya **subscription aktif**
2. Buka menu **Referral** di dashboard
3. Salin **kode referral** kamu (contoh: `BUDI-A3K9`)
4. Bagikan ke teman

Atau gunakan link langsung:
```
https://bikinbot.ai?ref=KODE_KAMU
```

## Cara kerja

| Event | Kamu dapat | Temanmu dapat |
|-------|-----------|---------------|
| Teman daftar + beli pertama | Komisi 10% | Bonus Rp 20.000 kredit |
| Teman top-up / perpanjang | Komisi 10% | — |
| Bulan berikutnya, bulan seterusnya | Komisi 10% | — |

**Contoh:** Jika teman kamu bayar Rp 200.000/bulan → kamu dapat Rp 20.000/bulan selama mereka aktif.

<Callout type="info">
  Komisi masuk ke **Saldo Referral** — terpisah dari kredit AI. Bisa di-withdraw ke rekening bank.
</Callout>

## Syarat mendapat komisi

- Akun kamu harus punya **subscription aktif** (tidak bisa pakai akun free/expired)
- Teman harus daftar menggunakan kode/link referral kamu
- Tidak ada batas jumlah teman yang bisa diajak

## Withdraw saldo referral

Saldo referral bisa di-withdraw setelah mencapai minimum **Rp 100.000**:

1. Buka **Wallet** di dashboard
2. Klik **"Withdraw"**
3. Isi nomor rekening atau e-wallet
4. Proses withdrawal dalam 1–3 hari kerja (butuh approval admin)

<Callout type="warning">
  Saldo referral **tidak bisa dipakai** untuk membeli kredit AI atau perpanjang subscription. Hanya bisa di-withdraw ke rekening.
</Callout>

## Ubah kode referral

Kamu bisa ganti kode referral satu kali:
1. Buka **Referral** di dashboard
2. Klik **Edit Kode**
3. Masukkan kode baru (huruf dan angka saja, tidak ada spasi)

<Callout type="warning">
  Setelah kode diubah, link lama tidak akan berfungsi. Pastikan update semua tempat kamu share link sebelumnya.
</Callout>
