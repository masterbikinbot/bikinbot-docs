# Generate Gambar

Bot kamu bisa membuat **gambar, ilustrasi, logo, banner, dan foto AI** langsung dari chat Telegram — tidak perlu aplikasi terpisah.

Harga: **~Rp 600–3.000 per gambar** tergantung model yang dipilih.

## Cara menggunakan

Cukup minta secara natural:

```
buatkan gambar kucing oranye bermain di taman bunga, gaya fotorealistik
```

```
buat logo untuk toko kopi namanya "Kopi Nusantara", minimalis, warna coklat dan krem
```

```
ilustrasi banner promosi diskon 50%, background merah, teks bold, modern
```

```
buat gambar produk parfum premium dengan cahaya studio, background putih
```

<Callout type="info">
  **Sertakan narasi teks dalam perintah** — detail yang lebih spesifik menghasilkan gambar yang lebih sesuai harapan.
</Callout>

## Tips prompt gambar yang efektif

| Elemen | Contoh |
|--------|--------|
| **Subjek** | "kucing oranye", "logo toko kopi" |
| **Gaya** | "fotorealistik", "ilustrasi kartun", "minimalis", "watercolor" |
| **Komposisi** | "close up", "wide angle", "bird eye view" |
| **Pencahayaan** | "cahaya studio", "sunset", "dramatic lighting" |
| **Warna** | "dominan biru dan putih", "monokrom" |
| **Detail tambahan** | "resolusi tinggi", "tajam", "detail" |

## Model gambar yang tersedia

| Model | Kualitas | Harga |
|-------|----------|-------|
| Gemini Flash Image (default Basic) | Baik | Rendah |
| Gemini Pro Image (default Pro/Ultra) | Sangat baik | Sedang |
| GPT-5.4 Image | Terbaik | Tinggi |

Model gambar dipilih otomatis berdasarkan tier botmu.

## Batasan

- Gambar yang mengandung kekerasan, konten seksual, atau melanggar copyright akan ditolak
- Resolusi output: hingga 1024×1024 (tergantung model)
- Satu perintah menghasilkan 1 gambar

<Callout type="warning">
  Generate gambar **memotong kredit AI**. Pastikan saldo kredit mencukupi (minimal Rp 5.000 untuk satu generate) sebelum request.
</Callout>
