# Custom Commands

Bot kamu mendukung **custom slash commands** — shortcut untuk tindakan yang sering dilakukan. Commands disimpan di file COMMANDS.md di workspace bot.

<Callout type="info">
  Pengelolaan commands dilakukan via chat langsung ke bot, bukan via dashboard.
</Callout>

## Cara membuat command

Minta bot via chat:

```
buat command /laporan yang akan membuat ringkasan aktivitas dan pengeluaran hari ini
```

```
buat command /ide untuk memberikan 5 ide konten untuk media sosial bisnis saya minggu ini
```

```
buat command /pagi untuk menampilkan todo list dan jadwal hari ini
```

Bot akan konfirmasi dan menyimpan command ke COMMANDS.md.

## Contoh command yang berguna

**Laporan harian:**
```
/laporan — ringkasan aktivitas + pengeluaran hari ini
```

**Brainstorm:**
```
/ide — 5 ide konten untuk media sosial minggu ini
```

**Checklist pagi:**
```
/pagi — todo list dan jadwal hari ini
```

**Template email:**
```
/email — bantu draft email profesional
```

## Lihat dan kelola command

Untuk melihat semua command yang aktif:
```
tampilkan semua command saya
```

Untuk hapus command:
```
hapus command /laporan
```

## Cara pakai

Ketik `/` di Telegram untuk melihat daftar commands yang tersedia (built-in + custom kamu).

<Callout type="warning">
  Commands hanya berlaku untuk bot kamu sendiri. User lain di luar whitelist tidak bisa menggunakan commands.
</Callout>
