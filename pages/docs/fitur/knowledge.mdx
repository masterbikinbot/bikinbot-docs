# Knowledge Base

Bot kamu memiliki file **KNOWLEDGE.md** di workspace yang dibaca otomatis saat sesi dimulai. File ini berisi konteks, informasi produk, panduan, atau data apa pun yang kamu ingin bot ketahui.

<Callout type="info">
  Upload file via dashboard tidak tersedia. Knowledge dikelola langsung via chat ke bot atau dengan meminta bot menulis ke file workspace-nya.
</Callout>

## Cara menambahkan knowledge

### 1. Ceritakan langsung ke bot (cara termudah)

Cukup ceritakan informasi yang ingin bot ingat:

```
Simpan ke knowledge base: Produk kami adalah software akuntansi untuk UKM.
Harga: Rp 500.000/bln. Fitur utama: invoice, laporan keuangan, integrasi pajak.
```

Bot akan menyimpan ke MEMORY.md atau KNOWLEDGE.md sesuai konteksnya.

### 2. Minta bot tulis langsung ke KNOWLEDGE.md

```
Tulis ke KNOWLEDGE.md:
---
## Produk: SoftAkun Pro
Harga: Rp 500.000/bln
Target: UKM Indonesia
Fitur: Invoice otomatis, laporan laba rugi, integrasi e-Faktur
---
```

### 3. Upload file teks via exec (untuk pengguna teknis)

Bot bisa membaca file yang ada di workspace-nya. Kamu bisa meminta bot untuk membaca file tertentu:

```
baca file yang ada di knowledge/ dan ringkaskan isinya
```

## Format yang optimal

Bot lebih efektif dengan knowledge yang terstruktur:

```markdown
## Nama Produk / Topik
Deskripsi singkat.

### Spesifikasi
- Poin 1
- Poin 2

### FAQ
**Pertanyaan:** ...
**Jawaban:** ...
```

## Batasan

| Parameter | Nilai |
|-----------|-------|
| Total workspace | 5 GB (Basic), 10 GB (Pro), 25 GB (Ultra) |
| Format teks | Plain text, Markdown |
| Kapasitas | Tergantung context window model yang dipilih |

<Callout type="warning">
  Bot membaca KNOWLEDGE.md di awal setiap sesi. Jika file terlalu besar (>30KB), bot mungkin menerima pesan "context truncated". Gunakan model dengan context window besar seperti `gemini-2.5-flash` (1M token) atau `deepseek-v4-flash` (1M token).
</Callout>

## Tips

- **Ringkas dan terstruktur** — gunakan heading dan bullet points
- **Perbarui secara berkala** — minta bot update knowledge saat ada perubahan info
- Untuk data yang sering berubah (harga, stok), pertimbangkan web search real-time daripada knowledge statis
