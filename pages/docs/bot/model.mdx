# Pilih Model AI

BikinBot mendukung **36 model AI** dari berbagai provider via OpenRouter. Setiap model punya karakteristik berbeda — kecepatan, biaya, kemampuan, dan spesialisasi.

## Cara ganti model

### Via Dashboard

1. Buka **Settings → Pilihan Model**
2. Pilih model dari dropdown (36 model tersedia)
3. Atau ketik ID model custom (format: `openrouter/<vendor>/<model>`)
4. Simpan — bot restart otomatis ~15 detik

### Via Telegram (sementara)

Ketik `/model` di bot untuk melihat picker model. Pilihan ini **hanya berlaku untuk sesi aktif** — tidak permanen.

Untuk ganti model secara permanen, minta bot via chat:
```
ganti model ke deepseek/deepseek-v4-flash
```

<Callout type="info">
  Ketik `/status` untuk melihat model yang sedang aktif digunakan bot kamu.
</Callout>

## Rekomendasi berdasarkan use case

| Use case | Model | Alasan |
|----------|-------|--------|
| Chat sehari-hari | `gemini-2.5-flash` | Cepat, murah (~Rp 15), multimodal |
| Paling hemat | `deepseek-v4-flash` | ~Rp 3/pesan, 1M context |
| Coding & agentic | `moonshotai/kimi-k2.6` (custom) | 262K ctx, tool calling kuat |
| Finansial/trading | `deepseek-v4-flash` | Gemini kadang strict di topik ini |
| Context sangat panjang | `x-ai/grok-4-fast` (custom) | 2M context window |
| Kualitas max | `claude-opus-4.5` | Reasoning terbaik |

## Custom model

Kamu bisa menggunakan model OpenRouter apa pun di luar 36 catalog:

```
openrouter/<vendor>/<model-id>
```

Contoh (model populer di luar catalog):
```
openrouter/moonshotai/kimi-k2.6
openrouter/x-ai/grok-4-fast
openrouter/deepseek/deepseek-v4-pro
```

Cek semua model yang tersedia di [openrouter.ai/models](https://openrouter.ai/models).

<Callout type="warning">
  Model dengan **context window besar** (1M+) lebih mahal per pesan jika history percakapan panjang. Gunakan `/new` secara berkala untuk reset context.
</Callout>
