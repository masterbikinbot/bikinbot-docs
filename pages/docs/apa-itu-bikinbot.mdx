# Apa itu BikinBot.ai?

**BikinBot.ai** adalah platform yang memungkinkan siapa saja membuat **AI Agent personal** di Telegram — tanpa coding, tanpa server sendiri.

Bot kamu ditenagai oleh model AI terbaru (GPT-5, Claude, Gemini, dan 36 model pilihan) dan bisa melakukan jauh lebih banyak dari chatbot biasa.

## Bukan sekadar chatbot

BikinBot berbeda dari chatbot biasa karena AI Agent kamu bisa:

- **Mengingat** konteks percakapan, nama, dan preferensi kamu
- **Membaca** file PDF, DOCX, gambar, audio, video
- **Browsing** internet secara real-time
- **Menjalankan** kode dan script (Python, Node.js, bash)
- **Membuat** gambar, video, dan musik dari teks
- **Terjadwal** mengirim reminder atau laporan otomatis

## Arsitektur Platform

### Alur pesan

```
 Kamu
  │  (chat di Telegram)
  ▼
 Telegram Bot API
  │  (webhook / long-polling)
  ▼
 OpenClaw  ──────────────────────────────────────────────────────┐
 (proses per-bot, isolated)                                      │
  │                                                              │
  │  kirim pesan + konteks                                       │ sync model,
  ▼                                                              │ billing, settings
 OpenRouter                                                      │
  │  route ke model pilihan user                                 ▼
  ├── GPT-5 / GPT-5.1 (OpenAI)               BikinBot.ai API  (Fastify)
  ├── Claude 4.5 / Opus 4.5 (Anthropic)               │
  ├── Gemini 3.1 / 2.5 (Google)                        │
  ├── Grok 4 (xAI)                                     ▼
  ├── DeepSeek V4 / R1                            Supabase
  └── 31 model lainnya...                   (database + auth)
```

### Komponen

| Komponen | Teknologi | Fungsi |
|----------|-----------|--------|
| **Dashboard** | Next.js + React | Konfigurasi bot, billing, settings |
| **API** | Fastify (Node.js) | Backend platform — auth, billing, bot management |
| **OpenClaw** | Node.js (per-bot process) | Runtime AI agent Telegram — per bot, isolated |
| **Database** | Supabase (PostgreSQL) | User, bot config, kredit, audit log |
| **AI Router** | OpenRouter | Proxy ke 36+ model AI dari berbagai provider |
| **Infrastruktur** | PM2 + Caddy + Ubuntu | Process management, HTTPS, server |

### Isolasi per-bot

Setiap user mendapat **satu proses OpenClaw terpisah** yang berjalan secara independen:
- Memory, context, dan file tidak bercampur antar user
- Crash satu bot tidak mempengaruhi bot lain
- Model AI dipilih per-bot, bukan shared pool

### Model selection (sejak v3.6)

Model dipilih **satu kali** oleh user — via Dashboard atau perintah chat ke bot. OpenClaw menggunakan model tersebut untuk **semua pesan** di bot itu. Tidak ada routing otomatis per pesan.
