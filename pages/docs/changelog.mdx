# Changelog

Semua perubahan signifikan di platform BikinBot.ai.

## v3.6 — 2026-05-25
_Pilihan Model: Lebih Banyak Model di Telegram + Simplifikasi Dashboard_

**✨ Baru**
- **Telegram `/model` picker sekarang menampilkan 36+ model** — sebelumnya hanya 4 pilihan. Kini semua model kurated tersedia dari Gratis (Gemma, Llama) hingga Premium (Claude Opus, GPT-5, Grok 4)
- **Dashboard tab berganti nama jadi "Pilihan Model"** — lebih jelas dan fokus

**🛠 Perbaikan**
- **Ganti model via dashboard langsung aktif di Telegram** — seed list model di config bot diperbarui otomatis
- **Smart Routing dihapus** — bot selalu menggunakan model yang kamu pilih, tidak ada pemilihan otomatis per pesan

**⚡ Lebih baik**
- **Dashboard Settings lebih bersih** — widget "Penghematan" dan banner Smart Routing dihapus, halaman lebih fokus

## v3.5 — 2026-05-25
_Platform Hardening + Referral Fix + Cron Optimization_

**✨ Baru**
- **Referral benefit sekarang benar-benar jalan** — fix constraint database yang salah. Referrer dapat komisi 10% per pembayaran; referee dapat bonus Rp 20.000
- **Referral commission tercatat penuh** — setiap komisi tersimpan di audit trail, tidak ada double-komisi

**🛠 Perbaikan**
- **Bot baru bisa dibuat lagi** — bug pada ExecStartPre unit systemd yang menyebabkan semua bot creation gagal sudah diperbaiki
- **Dashboard tidak error saat banyak tab dibuka** — fix AuthApiError dari concurrent Supabase session refresh
- **Bot yang sengaja distop tidak lagi direstart** — monitoring script tidak lagi salah deteksi bot stopped sebagai crash

**⚡ Lebih baik**
- 21 cron jobs diaudit, `wa-monitor` dihapus, 4 jadwal dioptimasi
- Guardian alert lebih andal (secrets di env file, cooldown per-bot)
- PM2 circuit breaker — stop restart setelah 10 crash berturut-turut
- OpenClaw diperbarui ke **2026.5.22**
